# davidguypugliese.com

Personal portfolio for **David Guy Pugliese** — Director of IT, AI Agent Infrastructure.

Live at [davidguypugliese.com](https://davidguypugliese.com).

## Stack

Static HTML + CSS. No build step, no JavaScript framework. Hosted on Cloudflare Pages, deployed automatically on push to `main`.

## Run locally

```sh
python3 -m http.server 8765
```

Then open <http://localhost:8765/>.

## Structure

- `index.html` — single-page portfolio
- `styles.css` — design tokens + layout
- `favicon.svg` — DGP monogram
